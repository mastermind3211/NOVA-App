# N.O.V.A. — Neural Android AI Assistant

## How to Build APK Automatically on GitHub
1. Extract `NOVA-Android-Project-Ready.zip` and upload the contents of the `NOVA` folder (including the `.github` hidden folder!) to a new GitHub repository.
2. Go to the **Actions** tab in your GitHub repository.
3. Select **Build NOVA Android APK** -> **Run workflow** (or push any commit to `main`).
4. Once the build completes, download **`NOVA-Debug-APK`** from the **Artifacts** section at the bottom of the workflow run page.
